# Feature Spec

Write a feature spec that a team can build from.

1. Gather the input (discovery brief, ticket, or description). Ask only for what is missing.
2. Write the spec with these sections:
   - **Goal and success metric**
   - **Scope** (in / out)
   - **User stories** with acceptance criteria
   - **Dependencies and risks**
   - **Open questions**
3. Keep it short and testable. Mark assumptions explicitly.
